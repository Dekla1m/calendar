# Мой день

Приложение-календарь и список дел. Проект запускается на Android и в браузере на компьютере. На Android записи хранятся локально в SQLite. Веб-версия — отдельный макет с демонстрационными данными: её изменения не синхронизируются с Android и сбрасываются при обновлении страницы.

## Использование на компьютере

Откройте [веб-версию](https://dekla1m.github.io/calendar/) в браузере. Она подходит для работы с календарём на десктопе. Отдельного установщика для Windows или macOS сейчас нет.

Чтобы запустить веб-версию локально, установите Node.js 22.13 или новее и выполните:

```sh
npm ci
npm run web
```

## Android APK

Готовый APK можно скачать из последнего успешного запуска **Actions → Android APK** в репозитории. Откройте запуск, скачайте артефакт `calendar-android-apk.zip` и распакуйте `app-release.apk`.

Сборка использует тестовую подпись для ручной установки. Она подходит для проверки на устройстве, но не для публикации в Google Play. Постоянный ключ подписи нужно отдельно настроить перед выпуском в магазин.

Сборка запускается автоматически после изменений в ветках `main` и `codex/initial-prototype`. APK также можно получить на вкладке [Actions](https://github.com/Dekla1m/calendar/actions/workflows/android-apk.yml).

## Разработка

Для работы нужны Node.js 22.13 или новее и npm. Команда `npm start` открывает меню Expo, где можно выбрать Android или web:

```sh
npm ci
npm start
```

Для локальной сборки Android требуется установленный Android SDK. В этом репозитории APK собирается GitHub Actions; Android Studio на компьютере для получения APK не требуется.

## GitHub Pages

Веб-проект собирается и публикуется командами:

```sh
npm run export:web
npm run deploy
```

В `app.json` задан базовый путь `/calendar` для страницы на GitHub Pages. Команда `deploy` отправляет папку `dist` в ветку `gh-pages`.

## Возможности и ограничения

- Есть список задач, типы записей календаря и просмотры дня, трёх дней, недели и месяца.
- Повторение записей: единоразово, ежедневно, еженедельно и ежемесячно. Для повторяющихся записей можно задать начало и конец периода.
- Календарь рассчитывает повторения до 2100 года. Запись на 29–31 число в коротком месяце переносится на последний день месяца.
- Просроченные записи календаря удаляются автоматически через месяц; для повторяющейся записи отсчёт начинается после окончания периода. Задачи при этом сохраняются.
- Данные Android-версии хранятся на устройстве. Облачной синхронизации между устройствами и веб-версией пока нет.
- События через полночь и длительностью в несколько дней пока не поддерживаются.

## Технологии

Expo SDK 57, React Native 0.86, React Native Web, TypeScript и SQLite через `expo-sqlite`. Expo CLI поддерживает запуск Android и web на Windows, macOS и Linux; веб-приложение работает в обычном браузере. Отдельные нативные сборки для Windows и macOS в проекте не настроены.
