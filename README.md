## START

# Мой день

Первый прототип личного календаря и списка задач для Android и веб-просмотра. Название и палитра временные: их предстоит согласовать после просмотра макета. Веб-версия содержит только вымышленные данные и хранит изменения до обновления страницы. На Android данные сохраняются локально в SQLite.

## Запуск

Требуются Node.js 22.13 или новее и npm. Проверено с Node.js 24.14.0.

```sh
npm ci
npm start
```

В меню Expo выбрать Android или web. Для отдельного веб-запуска: `npm run web`. Приложение не требует сервера для работы с задачами и записями после установки APK.

## Веб-сборка и GitHub Pages

```sh
npm run export:web
npm run deploy
```

`app.json` содержит `experiments.baseUrl: "/calendar"`, поэтому ресурсы собираются для адреса `https://dekla1m.github.io/calendar/`. Команда `deploy` публикует `dist` в ветку `gh-pages`; в настройках репозитория Pages нужно выбрать эту ветку и каталог `/`. Для публикации требуется работающий доступ Git к GitHub. Наличие права `push` в подключении GitHub само по себе не подтверждает работу локального Git. Веб-версия не читает базу Android.

## APK

После входа в Expo и установки EAS CLI:

```sh
npx eas-cli build --platform android --profile preview
```

Профиль в `eas.json` запрашивает APK для внутренней установки. Сборка и проверка на физическом Xiaomi ещё не выполнены.

## Данные

- `categories` и `tasks` — независимый список дел. Удаление категории переводит её задачи в системную «Без категории».
- `event_types` и `calendar_events` — независимые типы и записи календаря. Удаление типа переводит записи в системное «Другое».
- Дата хранится как локальная строка `YYYY-MM-DD`, время — `HH:mm`. Это сохраняет выбранные пользователем дату и часы без неожиданных преобразований часового пояса.
- Схема SQLite создана миграцией версии 1 через `PRAGMA user_version`. Личные демонстрационные данные на Android не создаются.

## Текущий этап

Есть экраны задач, дня, трёх дней, недели и два варианта месяца. Доступны создание, редактирование и удаление задач, категорий, календарных записей и типов. Временная шкала показывает интервалы каждые 30 минут и разносит пересекающиеся записи по колонкам. Веб-проект экспортируется статически.

До готового релиза остаются визуальная проверка на узком экране и Xiaomi с системным масштабированием шрифта, публикация Pages, сборка и установка APK, проверка сохранения данных после перезапуска на устройстве. Два варианта месяца требуют выбора пользователя. Записи через полночь и на несколько дней пока не поддерживаются.
