# Проверка ТЗ и технологий — 28.09.2026

## Вывод

React Native, Expo и TypeScript подходят для Android-приложения с веб-макетом. На дату проверки стабильная линия Expo — SDK 57, совместимая с React Native 0.86 и Node.js от 22.13. Установленный Node.js 24.14 удовлетворяет минимальному требованию. `expo-sqlite` поддерживает Android и сохраняет данные между перезапусками.

Expo Web и GitHub Pages остаются пригодны для публичного макета. Для репозитория `calendar` нужен `experiments.baseUrl: "/calendar"`; Expo указывает это свойство как экспериментальное. Статический экспорт создаётся командой `expo export -p web`, затем можно публиковать ветку `gh-pages` с отключённым Jekyll.

SQLite на web пока имеет статус alpha и требует WASM и специальных COOP/COEP-заголовков сервера. Поэтому веб-макет намеренно работает с отдельным набором вымышленных данных в памяти, а Android использует SQLite. Это соответствует границе данных из ТЗ и позволяет разместить предпросмотр на GitHub Pages без сложной серверной настройки.

Для APK официальный путь Expo — EAS Build с `android.buildType: "apk"`. Это требует входа в Expo и дальнейшей проверки на устройстве. Наличие Android Studio не обязательно при облачной сборке.

## Требующие решения пункты ТЗ

1. Название и иконка: `Мой день` пока служит рабочим названием; иконка ещё не подготовлена.
2. Месяц: пользователь выбрал вариант «А · Сетка»; вариант «Б · Лента» удалён из интерфейса.
3. Палитра и близость к референсу: по обратной связи интерфейс переведён на тёмную тему с фиолетовым выделением текущей даты.
4. Повторы, переход через полночь, резервная копия и виджет оставлены за рамками первой версии согласно ТЗ.
5. Сборка APK и проверка на Xiaomi требуют физического устройства. Локально проверены TypeScript, веб-экспорт и сборка Android-бандла; поведение на устройстве ещё не проверено.
